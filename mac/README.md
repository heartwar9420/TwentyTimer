# TwentyTimer for macOS

依照 20-20-20 原則的護眼提醒工具：每工作 20 分鐘，看向 20 英尺（約 6 公尺）外 20 秒。

macOS 原生版（Swift + SwiftUI），選單列常駐。

## 特色

- **選單列常駐**，顯示剩餘時間，不佔 Dock、不佔 Cmd-Tab
- **低調的休息提示**：右上角 280×148 的毛玻璃小面板，不搶焦點、不打斷打字，可拖曳
- **不點按鈕就不會開始下一輪**——離座回來一定看得到，也不會空轉浪費一輪
- **零權限的閒置偵測**：用 macOS 原生 API，不需要輔助使用或輸入監控授權
- **開會時自動延後**：偵測到有 App 在使用麥克風就先不打擾，通話結束才提醒
- **提示音可放大**：系統提示音比音樂小得多，音量可調到 300%（軟限幅避免破音），
  音效清單依實測響度由大到小排序
- **可完全靜音**：在辦公室純靠視覺提示

## 建置

只需要 Command Line Tools，**不需要完整的 Xcode**。

```bash
./build.sh
open build/TwentyTimer.app
```

產出 `build/TwentyTimer.app`，可以直接拖到「應用程式」資料夾。

## 使用

點選單列圖示開啟面板：

- **暫停計時** — 凍結工作倒數
- **立刻休息** — 跳過剩下的工作時間直接進入休息
- **勿擾 30 / 60 分** — 計時照常進行，只是時間到不跳彈窗，等勿擾結束才提醒
- **設定** — 時間長度、音效、勿擾、開機自啟
- **統計** — 每日輪數、連續天數、歷史紀錄

## 資料位置

```
~/Library/Application Support/TwentyTimer/
├── config.json   設定
└── stats.json    統計
```

格式與未來的 Windows 版共用，詳見 [SPEC.md](SPEC.md)。放進 iCloud Drive 就能兩台電腦同步統計。

## 開機自啟

「設定 → 登入時自動啟動」使用 `SMAppService`，需要 App 是完整的 bundle
（也就是要透過 `build.sh` 產生的 `.app` 執行，直接跑 `swift run` 不會生效）。

## 已知限制

- 全域快捷鍵尚未實作
- 勿擾偵測只看麥克風，還沒偵測螢幕分享 / 錄影
- 未做開發者簽章與公證，第一次開啟若被 Gatekeeper 擋下，請在
  「系統設定 → 隱私權與安全性」按「仍要打開」
